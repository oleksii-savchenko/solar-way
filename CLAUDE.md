# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

Лендинг solarway. Стек: Astro, GSAP.

Проєкт ще не ініціалізовано: після створення Astro-проєкту перевір команди нижче за `package.json` і додай сюди лінт і тести, якщо вони з'являться.

## Команди

- `npm run dev` — дев-сервер
- `npm run build` — продакшн-збірка
- `npm run preview` — перегляд збірки

## Правила

- **Контент:** усі тексти й зображення — у файлах контенту (`src/content/`). У компонентах жодних захардкоджених текстів чи шляхів до зображень.
- **Секції:** кожна секція — окремий компонент (`src/components/sections/`). Сторінка лише збирає секції.
- **Стилі:** кольори, шрифти й відступи — лише через CSS-змінні (`src/styles/variables.css`). Жодних значень напряму в компонентах.
- **Адаптив:** mobile-first. Базові стилі для мобільних, ширші екрани — через `min-width`.
- **Стиль роботи:** пиши коротко — і код, і відповіді.

## Економія токенів

- Не роби скріншотів сайту і не відкривай браузер для перевірки, якщо я прямо не попрошу. Результат у браузері я перевіряю сам.
- З Figma бери тільки фрейм, посилання на який я дав, а не весь файл.
- Не запускай збірку проєкту (build) після кожної зміни. Локальний сервер оновлюється сам.
- Читай тільки ті файли, які потрібні для поточної задачі. Не переглядай весь проєкт без потреби.
- Змінюй тільки те, про що я прошу. Не переписуй і не «покращуй» інший код.
- Не створюй README, звіти та файли документації, якщо я не прошу.
- Відповідай коротко: які файли змінені і 1–2 речення про суть. Без довгих пояснень.
